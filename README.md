# 施設基準届出データベース(試験公開)

全国の保険医療機関・保険薬局について、各地方厚生局が公表する「施設基準の届出受理状況(届出受理医療機関名簿)」を、
ブラウザで検索できるようにした試験公開のサイトです。サーバー側の検索処理はなく、ブラウザの中で動く
DuckDB-Wasm が Parquet ファイルを直接読んで検索します。

公開ページ: https://sabanoko.github.io/facility-standards-viewer/ (公開の準備ができ次第)

## 内容

- 施設名・届出名称からの検索、届出名称からの逆引き(どの施設が届け出ているか)、施設の詳細(届出の一覧、病床数など)
- 月ごとの変化(届出名称ごと・局ごとの施設数の推移。月は名簿の「現在日」の月)
- 地図(東京都の一部。住所から推定した位置)
- 対象: 関東信越・北海道・東北・東海北陸・近畿・中国四国・四国・九州の8局の医科・薬局

## 加工の表示

「施設基準の届出受理状況(届出受理医療機関名簿)」(各地方厚生局)をもとに、国際医療福祉大学 石田円研究室が、
全国8局のデータの統合、検索用の形式(Parquet)への変換、届出名称の整理、届出ごとの病床数の抽出、月ごとの集計、
住所からの位置の推定を行って作成しました。加工・編集の内容は国際医療福祉大学 石田円研究室の責任によるもので、
国(厚生労働省・各地方厚生局・国土交通省)が作成・公表したものではありません。

「位置参照情報ダウンロードサービス」(国土交通省)をもとに、住所から位置を推定する加工を行っています(街区単位の精度で、建物の正確な位置ではありません)。

## データの時点の考え方

- 「現在日」: 各局が名簿の先頭に記載している「令和○年○月○日現在」(データ時点)です。月ごとの変化の「月」は、この現在日の月です。
- 「取得日」: 運営者が各局のページからデータを取得し、取り込んだ日です。
- 「最終確認日」: 毎週の確認で、公表元のファイルが前回の取得分から変わっていないと最後に確認した日です(取得日とは別の項目)。
- 名簿には「主名簿」と「項目別」があり、局によっては項目別が主名簿より古いまま更新されないことがあります(ページの表で強調しています)。

## ファイル

- `index.html` … ページ本体
- `national_medical_facilities.parquet`、`national_medical_filings.parquet`、`national_medical_filing_beds.parquet` … 医科の施設・届出・届出ごとの病床数の内訳
- `national_pharmacy_facilities.parquet`、`national_pharmacy_filings.parquet` … 薬局の施設・届出
- `monthly_filing_stats.parquet` … 月ごとの集計
- `tokyo_medical_geocoded.parquet`、`tokyo_pharmacy_geocoded.parquet` … 東京都の施設の推定位置
- `data_meta.json` … 取得日・現在日・最終確認日
- `filing_name_relations.csv` … 届出名称の関係(出典で確認できたものだけ画面に出します)

### 同じ施設・同じ届出名の届出が重なるとき

項目別にだけ載っている届出が、同じ施設・同じ届出名(番号は違う)の主名簿の届出と重なることがあります。
次のすべてに当たる届出は、主名簿で番号が付け替えられた古い番号の届出と考えられるため、届出の一覧・月ごとの集計のどちらにも含めていません
(① 同じ施設・同じ届出名の届出が主名簿にある、② その番号が同じ局の以前の主名簿に載っていた、③ 算定開始日が主名簿の同名の届出より古い)。
重なっていても、これに当たらないもの(病棟を増やした追加の届出などの可能性もあります)は、数えたうえで、
`national_medical_filings.parquet` の `same_name_in_main` を真にし、`monthly_filing_stats.parquet` の `n_same_name_in_main`(件数)・`beds_same_name_in_main`(病床数の合計)に入れています。
これらを除いた値も、そこから計算できます。付け替えかどうかは、データの状況から判断したもので、各厚生局の説明は確認していません。

Parquet は ZSTD で圧縮しています。ページは、起動時に施設の2ファイルだけを読み、届出・病床数の内訳・月ごとの集計・座標は、それを使う画面を初めて開いたときに読み込みます。

このリポジトリは毎月、履歴を残さずに上書きして更新します(過去の版は残りません)。
